# Artwork-led design

The user's illustrations are the source of truth: strong black outlines, imperfect rounded shapes, soft club green, heart pink and red, orange diamonds, and warm crown yellow. PNG cards and suit icons are used throughout. Home, controls, profile frames, rules illustrations, and dialogs share the same outline weight and offset shadows.

Bricolage Grotesque is bundled locally, including its SIL Open Font License. Its irregular, rounded forms complement the drawing style. Main text is 16px or larger; compact supporting labels are 14px.

The table is always 1:1. Its circular surface uses equal insets; phase controls never resize it. Start game sits in the centre. No trick totals appear before starting, and dealer removal controls occupy that space instead.

Motion includes a short card fan entrance, button presses, seat selection wiggles, crown landing, trick collection, count pops, and modal transitions. All are disabled when reduced motion is requested.

`/dev` retains all screen/phase previews, 52 cards, card states, and a two-tap hand. Uploaded originals are preserved; the asset preparation script makes mobile-sized display copies.
